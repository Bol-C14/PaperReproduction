# DeepCell bounded CPU protocol v1

Frozen before dependency installation, checkpoint loading or inference, 2026-10-28. Scope: checkpoint architecture coverage and tiny synthetic paired-view integrity, then CPU encoder inference only. No training, fusion-quality claim, ECO, mapping, GPU, paid/API resources, gated assets, or push. Setup bound: 2 hours, 2 GB aggregate downloads, current CPU and 16 GiB memory cgroup; use at most 2 CPU threads. Stop at the validation/inference milestone or a required-asset block.

Upstream: immutable source snapshots in ../sources/code, commit b82aef22559c6d8c52eb4feb437ebdd32709360e. Leave upstream untouched. Pilot files and adaptations live here. Only named AIG DG2 and PM DG2 encoder checkpoint binaries may be fetched, from that same commit. Inspect archive, then torch.load(weights_only=True, map_location='cpu'); no unrestricted pickle fallback. Compare every model state key, shape, and dtype. Strict loading must cover 100% of model state before calling a checkpoint compatible. Record epoch and available metadata, with training lineage unknown.

Use the upstream encoder/aggregation code if dependencies can be installed cheaply. If packaging imports irrelevant encoders/trainers, a narrow isolated-module adapter may load only the required upstream modules; document it. A replacement aggregator or forward path requires explicit independent parity checks. Do not call a partial parameter load compatible.

Construct three synthetic parent designs with different Boolean functions: xor(a,b); mux(s,a,b); majority(a,b,c). Give each two logically equivalent PM variants, with explicit pin order and 64-bit repeated truth-table features. Lower their cells into AND/NOT AIGs with explicit PM-output -> AIG-signal correspondence and PI/PO maps. Keep parent identifiers and all variants in one split: train=xor, validation=mux, test=majority. These are integrity partitions only; no model fitting or generalization estimate.

Independent oracle: exhaustive Python Boolean-expression truth tables using itertools, separate from PM table lookup and AIG gate evaluation. All PM and AIG outputs must match the oracle on every input assignment; record exact internal-node probabilities by enumeration, without treating them as original paper labels. Validate DAG order, edge index ranges, pin/table convention, mapping consistency, parent disjointness, and reject a deliberately mismatched pair and deliberately contaminated split. Synthetic PM cells are a teaching library, not paper Liberty assets or commercial technology mapping.

After strict checkpoint compatibility, run both real encoders on every pair in eval/inference mode, with fixed Python/NumPy/Torch seeds. Record shapes, finite values, probabilities and exact-oracle mean absolute errors, nodewise output, elapsed CPU time and process peak RSS. Repeat a fixed case with seed reset to check determinism; note upstream random structural initialization. Include two-input AND/OR/NAND/NOT elementary controls if convenient. Never infer general quality from tiny synthetic cases. No threshold on prediction accuracy: this pilot tests compatibility/execution, not paper metrics.

Controls: functional equivalence has zero truth-table disagreements; mismatched pair must be rejected; contaminated parent split must be rejected; all model state tensors strictly covered; outputs finite; expected structural/functional dimension=128; fixed-seed repeat identical. Any fail is reported, not silently edited out. If a protocol change is needed, record it before rerunning.

Commands, dependency/download sizes, checksums, errors, times and outputs go into logs/results. No external publication. Retain asset audit as historical audit-only work and add PILOT_REPORT.md separately. Stop when this milestone is documented.

Frozen before corpus creation or training, 2026-10-28. Extends (does not overwrite) the earlier audit and encoder-only pilot. No additional downloads, GPU, external inference API, paid resources, credentials, gated access, security changes, uploads, remote writes or push. Existing 4-core/16GiB cloud cgroup; Torch threads=2. Read-only instruction search found no AGENTS.md or skill files in repository/workspace .agents (directory empty). No applicable security or generic data-analysis workflow is invoked for this coding/reproduction task.

Scientific question: can paired PM/golden-AIG representation learning help reconstruct masked circuit semantics and prioritize signals for independently correct functional ECO? This is an independent reconstruction using official encoders and newly generated Boolean circuits, not the original released downstream algorithm or benchmark reproduction.

Architecture: unchanged official PM DG2 and AIG DG2 128-dimensional structural + functional channels. AIG uses the previously documented strict encoder/probability-only contract (missing auxiliary connectivity head); PM full class strict. AIG frozen; PM trainable in probability adaptation, MCM, and ECO finetuning. Same 4 TransformerEncoder layers, 8 heads, d_model256, FF2048 and dropout0.1 as the ordinary upstream Transformer path. Mask functional channels only, retain structure; choose max(1,floor(.05*PM_nodes)) roots and 4 fan-in hops; report actual fraction. No cross-view node-correspondence input, extra positional or modality embeddings. PM probability loss and functional-channel reconstruction L1 weighted equally. Unlike upstream code, implement paper-stated frozen AIG. CPU batches=4 (paper scale not reproduced).

Synthetic corpus: six primary inputs, train families parity/muxbank/arithmetic (24 distinct parent Boolean functions each), validation family conditional (12), test families majority/comparator (12 each). Two serialization/cell/wire variants per parent. All parent descendants in one split; reject identical 64-bit output truth signatures anywhere among distinct parent IDs. Family sets also disjoint. Exhaustively compare PM, independently evaluated AND/NOT AIG lowering, and a separate direct Python family oracle for all 64 assignments; verify internal PM/AIG maps but do not give maps to the learned model. Exact probabilities and ancestry labels are newly computed, not invented original-paper labels. Reconstructed simple cell library and SOP AIG lowering are explicit substitutions for Liberty/commercial mapping/ABC strash.

Bounded preflight: small sliced train/validation/test sets, one seed, one epoch per phase. Check finite forward/backward and record costs. If the full-shaped path fits <2GiB RSS and conservatively predicts <45 min CPU wall clock for the declared main comparison, run the main protocol without selecting variants or tuning on test results. Main comparison seeds208/209, five arms: paired official initialization, PM-only official (other-view zero tokens), shuffled-AIG official, paired random encoder initialization, paired official without MCM reconstruction pretraining. All arms receive equal PM probability adaptation (2 epochs), stage2 schedule (6 epochs; no-MCM arm probability-only), ECO finetuning (6 epochs). Adam lr1e-4; no early stopping or checkpoint selection. Other-view shuffle within split with deterministic different parent, never across splits. Same train order/targets/masks per seed; same initial fusion/rank weights across arms. Random arm receives the same PM optimization schedule but frozen random AIG, explicitly a warm-start contribution control, not equally pretrained encoders. Before/after MCM family-held-out probability and reconstruction metrics; compare downstream at identical budgets. No hyperparameter search.

Functional ECO reconstruction: known patch site, single unknown cell cut (incoming pins/function erased from observed PM; original candidate signals retained). This is a less extensive corruption than paper's described full-cone deletion. Rank legal non-descendant candidate signals with MLP([refined node,refined patch token]); finetune BCE for original target fan-in ancestry plus teacher embedding reconstruction of missing target. Teacher golden PM/ancestry used in training only. Golden AIG is the second input; at inference no golden PM function/pin/ancestry labels or PM-to-AIG internal map enters ranking or patch solver. This direction of ancestry labels is an explicit interpretation/substitution, not a claim to recover the authors' unpublished exact ECO labels.

Exact downstream engine: independently enumerate all 64 PI assignments. For each pattern evaluate observed PM with patch variable0 and1; compare complete PO to golden AIG PO to derive required patch value or don't-care. Test candidate-prefix feasibility without internal golden target labels. At candidate budgets1..3, synthesize a table when constraints consistent; lower the resulting patch to explicit AND/NOT gates. Validate patched full circuit against independent direct family oracle on all inputs. Report success@3, first feasible support budget, synthesized gate count, ancestry recall@3 and average precision, actual solver/overall time and counterexamples. Record baseline random and reverse-topological ranking plus hidden-golden-direct-fanin oracle upper bound (clearly marked inaccessible to learner). PI fallback (up to6 inputs) is a separate correctness safety check, never counted as learned budget success. Store actual patch netlists and independent replay verifier. No claims about ABC runeco/technology mapping/physical timing ECO or paper costs.

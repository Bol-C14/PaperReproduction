# Public DeepCell research export

This paper branch is a sanitized publication snapshot. Original local commits and experiment files are preserved in the selected cloud workspace; see PUBLIC_EXPORT_MAPPING.json for the source commit mapping and exact per-file original/public SHA256s. The public history uses neutral noreply attribution rather than copying local personal commit-email metadata.

The export removes host-environment details from an installer report, replaces local runtime paths in two install logs, and removes one upstream author-specific Conda installation prefix. Dependency names, versions, requirements, source URLs/archive hashes and actual installation outcomes are retained. Integrity indexes explicitly retain original execution hashes alongside public redaction hashes. No runtime code, numerical metrics, input corpus, model scores, patch netlists or formal-check results were changed. Reports describe the original execution; the public environment YAML is the one metadata-only sanitized upstream snapshot.

Read CLOSURE_REPORT.md for bounded claims: the learned representation-to-patch loop executed, but paired-view pruning benefits and original paper results were not reproduced. Full-token paired ECO success was10/96 versus12/96 for PM-only; learned public EPFL top-three repairs failed. Oracle/fallback repairs passed independent formal checks. These failures and substitutions remain published.

Included: official small source/config snapshots, independent reconstruction code, frozen protocols, replay commands, actual datasets/metrics, logs, small explicit repair outputs, formal-check evidence and SHA256 provenance. Omitted: installed environments/caches, generated archives, large model weights, downloaded ABC source/build. Official checkpoint URLs/hashes and all14 locally trained checkpoint hashes remain in the asset indexes. Native ABC source commit/build flags and public benchmark provenance are recorded for rebuilding. No archive upload or remote visibility/access change is performed.

Publication safety check scans all proposed reachable blobs and commit metadata for credentials, token/key patterns, authentication/cookie values, embedded URL credentials, host-environment dumps and local/internal path/service data. Existing public upstream contact details in the verbatim research README are retained as source attribution. A clean pattern scan is evidence of the check scope, not a guarantee that every conceivable secret format is detectable.

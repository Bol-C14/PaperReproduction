# 后续研究机会

以下是由本次证据边界产生的可检验研究问题，不是宣称已经获得的收益。

| 问题 | 最小有区分力的实验 | 成功/失败判据 |
|---|---|---|
| 结构相似是否预测可迁移配置 | 冻结donor预算，目标整家族留出；在独立审计预算下测全部donor选中配置，报告similarity与transfer regret的秩相关；基线用简单节点计数、面积规模、随机donor、全局最佳donor | 高HR而低相关/高regret即不支持结构检索对调参有用；避免只报告“相同功能命中” |
| LLM的增量价值是什么 | 可访问免费模型上固定AST、BO、donor库与总成本；AST-only、text-only、分层摘要+AST、仅端口/位宽摘要；完整记录输入输出、错误JSON、token数、CPU时间 | 改善必须超过同等推理时间可换取的额外EDA探索；模型失败/无提升也报告 |
| tournament是延迟剪枝还是更多机会 | 比较单父、多父无剪枝、立即剪枝、短暂宽限后剪枝；固定总阶段调用和CPU秒，复用同样父产物；前瞻禁止额外目标oracle | 同预算时多父无剪枝已解释收益，则不能把它归为剪枝；记录被剪枝父若继续运行的机会损失，但反事实EDA另外计费 |
| HASTE保留了什么 | 分离节点类型、位宽、依赖边、运算常数；改变hash维数/seed与权重；用语义等价重构、非等价但同AST外形的设计 | 若小seed变化会翻转donor，报告不确定性；检索须支持“无合适历史设计”而非总强选 |
| 跨阶段代理模型的错误代价 | 目标不是仅预测早期QoR，而是预测下游transfer regret及不确定性；用保守置信界决定是否延后剪枝 | 早期不佳但最终最佳的候选保留率提高，且同总预算改善终态QoR；不能只看代理拟合误差 |
| 历史数据库何时回本 | 一次性完整计费、可审计的多目标摊销、持续数据库三种协议；按时间切分，冻结检索权重，记录每个新增case的贡献 | 给出break-even目标数及置信范围；不将预训练/历史调参/失败案例清洗成本隐藏为零 |
| 工业流程外推是否成立 | 先扩至真实较大开源RTL，加入CTS和routing，以及紧时序/功耗活动率敏感性，再讨论商业工具 | 必须补齐阶段间artifact校验、约束完整性及失败率；只在小电路放置成功不算外推成功 |

优先级：先完成家族隔离的transfer regret研究，因为它直接检验“相似电路值得转移参数”这一前提；若前提不足，增加更大LLM可能只是增加成本。其次做总机会预算对齐的多父/剪枝比较。模型下载被403阻断时不应把回放或确定性文本控制当作真实在线LLM实验。

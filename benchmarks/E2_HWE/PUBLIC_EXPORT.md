# Public export boundary

The export consists only of the reviewed files under `benchmarks/E2_HWE` listed in `payload_checksums.json`, plus that checksum inventory itself. Host-specific evidence locations, hidden verifier inputs, reference patches, implementation mutant patches and output vectors are withheld. Private evidence identifiers and relative bundle-member hashes provide linkage without publishing host paths.

The dataset source note is original review text with source attribution, replacing the upstream README reproduction. Upstream source/data/hardware licenses remain described separately; no image or hardware source is redistributed here.

Publication corrections change documentation, portable evidence linkage and regeneration behavior only. Calibration outcomes, source/dataset/image pins, timings, scoring controls, independent contract counts and all private raw evidence remain unchanged. The proposed public commit is rebuilt directly from the existing published baseline; the prior unpublished export is retained only by a local private reference and is not an ancestor of the proposed public head. No push is authorized or performed.

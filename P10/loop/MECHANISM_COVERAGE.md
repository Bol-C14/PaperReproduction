# Mechanism coverage and provenance

All code in this directory is **independent reconstruction**. No Intel ROVER source has been obtained. Source: [accepted manuscript](https://spiral.imperial.ac.uk/bitstreams/de68c6e8-a66d-42d6-ae3e-16eab9fc9782/download); definitions cross-checked in [author thesis Chapter5](https://samuelcoward.co.uk/assets/pdf/Thesis_Imperial.pdf), which explicitly identifies the TCAD extension. Page numbers below are printed manuscript/thesis pages.

| Paper mechanism | Evidence | Reconstruction / limit |
|---|---|---|
| E-graph constructive equality saturation | Paper §II/IV, Fig3 | Actual Rust egglog14 through Python low-level bindings; algebraic e-matching, union and congruence closure. Eight bounded rounds; no claim every run reaches mathematical saturation. This substitutes egglog for egg. |
| ASSUME subdomain congruence and bottom | Paper §III pp4–5; thesis pp88–91 Eqs5.5–5.9/Table5.1 | ASSUME nodes preserved inside e-graph. Create branch assumptions and propagate strict arithmetic with operand widths retained. Only erase care wrappers during whole-module lowering; unconditional Z3 and Yosys RTL SAT must pass. Earlier fixture phase independently checks definedness/bottom and Combine. Current kernels single-level branches; nested Combine is not in this end-to-end rule subset. |
| Live-class relevance analysis | Paper §III; thesis p90 | v3 fixedpoint reachable e-class sets, restricted to expression classes (width/name primitives excluded). Apply overlap filter to Create/Propagate; compare against v2 unfiltered runs. |
| RTL value analysis and refinement | Paper §IV-A pp6–7; thesis pp96–98 | External fixedpoint per e-class, intersection across equivalent representatives, unsigned interval hull, conservative modular Add/Mul/Cut, bound refinement under Ult/Not-Ult and signed nonnegative guard. Generic signed operator transfers and interval-union lattice are not integrated into the e-graph; earlier separate interval-union signed fixture remains evidence, not a claim of complete support. |
| Guarded shifts / signed simplification | Paper p3 Eq1, p10 Eq24; thesis p106 Eq5.19 | Bound logical shift amount and simplify signed abs only under proven nonnegative care. No arithmetic-shift or X/Z semantics claim. |
| Independent operand/result bitwidth reduction | Paper §IV-B; thesis p101 Table5.4 | v1–v3 narrowed operands only when result narrowed, leaving a coverage gap. v4 completes independent p',q',r' calculation, including full-width modular result with narrow operands. Controls use same v4 rule/cost policy. |
| Delay-cost evaluation | Paper TableII, §IV-C pp8–9 | Width-aware component proxies and longest data path; declared formulas, uncalibrated. Generic gate count/depth from Yosys is independent evaluation, not the extraction objective or TSMC STA. |
| DAG sharing, acyclicity, constrained extraction | Paper pp8–9 Eqs16–22; thesis pp102–104 | v2+ binary selected nodes/classes, closure, ranks, arrival inequalities and exact modeled-area minimization using Z3 instead of CBC. Check objective lower=upper. Two delay-target samples dmin and2*dmin, not entire Pareto frontier. Initial tree DP is a **new baseline**, not a faithful paper extractor. |
| RTL input/output | Paper Fig3 Slang / VeriLang | Hand-authored typed arithmetic IR replaces SV frontend. Actual generated original/candidate Verilog parsed by Yosys; width casts emitted as separate wires. No general SystemVerilog elaboration, sequential circuits, retiming or arbitrary RTL ingestion. |
| Independent equivalence | Paper Fig3 / §V | Whole-domain Z3 BV comparison, then separately parsed RTL SAT miter in Yosys. No external assumptions. Negative signedness/truncation/guard controls must fail in BOTH checkers. No industrial EC certificates or cross-tool proof certificate verification. |
| Physical comparison | Paper §V TSMC5 + commercial tool | Free generic Yosys `synth -noabc` provides cell count and combinational levels. No physical timing, cell-library area, power, placement or original30%/1% result claim. |
| Paper benchmark population | Paper TableIII | Six newly authored methodology kernels at8/16bits (12 instances), not the original industrial suite or full floating-point subtractor. Signed corner cases and full input bit patterns checked symbolically. |

Legitimate free tool sources: [egglog Python](https://github.com/egraphs-good/egglog-python) (MIT), [Yosys](https://github.com/YosysHQ/yosys) (ISC), [YoWASP packaging](https://github.com/YoWASP/yosys) (ISC, explicitly unofficial Yosys build), [Z3](https://github.com/Z3Prover/z3) (MIT). Packages and all resolved wheel hashes are pinned in requirements.lock / SOURCE_VERSIONS.json. No dependency upstream repository was edited.

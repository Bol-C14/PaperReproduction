# CircuitFusion bounded CPU milestone

This is a **method port on self-authored synthetic cones**, with randomly initialized 28,736-parameter models. It is not a full upstream installation, pretrained reproduction, production synthesis flow, or PPA experiment. See `MILESTONE.md` for results and limits.

- `upstream_original/`: untouched partial public source snapshot; checksums in `provenance.json`. Upstream reuse license remains unresolved. Not a complete runnable checkout.
- `repaired/` and `repairs.patch`: narrow fixes to HDL fusion mixing, summary export and gradient accumulation. The optional `modality_mix_alpha` defaults to 0.5, matching the original matching path. Full upstream execution and multi-GPU behavior are untested.
- `tests/test_repairs.py`: executes actual AST-extracted functions/loop with deterministic lightweight collaborators. Checks behavior without importing DGL/BERT or using gated weights.
- `pilot/PROTOCOL.json`: frozen design, seeds, controls, budgets; SHA256 verifies unchanged protocol at run start.
- `pilot/data.py`: exact 3-bit expression evaluator, equivalent-view construction, synthetic gate lowering and integrity checks. Each cone is a combinational next-state function; register extraction/reset/clock semantics are outside this milestone.
- `pilot/run.py`: HDL and summary GRUs, RTL graph message passing, summary-query cross-attention to HDL/graph memory, gate-graph encoder, intra-RTL contrastive and cross-stage alignment objectives.
- `results/`, `logs/`, `COMMANDS.md`, `requirements-cpu.lock`: inspectable evidence and commands.

Run the two control scripts first with the local `.venv/bin/python`; `pilot/run.py` reruns the full frozen nine-arm pilot and overwrites its generated result files. Do not rerun merely to seek a better result. Fresh installations should use the official PyTorch CPU package index with the recorded lock; this environment setup succeeded, future availability is not guaranteed.

No official missing labels are fabricated. Gate netlists are implementation representations generated by an exact handwritten Boolean lowering, not technology-mapped commercial netlists. Template-derived summaries are weaker evidence than independent natural-language understanding. This milestone keeps the gated NV-Embed boundary intact.

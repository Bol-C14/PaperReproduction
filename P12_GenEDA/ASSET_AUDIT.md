## Mechanism boundary

The paper uses frozen NetTAG circuit representations. Embedding alignment learns a connector and then tunes the decoder with it; prediction alignment passes learned gate-function predictions to a frozen decoder. The reported preparation uses 25k subcircuits, 50k augmented samples and a 400-circuit test set; synthesis uses Design Compiler/NanGate45. The reported server has eight A800 80GB GPUs. These are paper settings, not measured minimum requirements. [Paper §§V–VI](https://arxiv.org/html/2504.09485v2)

The released implementation makes the embedding interface concrete: `llava_arch.py` sets `mm_hidden_size = 768`, projects input graph features with `mm_projector`, and inserts them into language embeddings. `run_llava.py` reads `design['graph']` and a conversation target; `train.py` accepts the same graph field. The circuit scripts select DeepSeek-Coder-1.3B, connector pretraining, then LoRA with rank 128 and alpha 256. Their connector is `mlp2x_gelu`, implemented as two linear layers with GELU. These are direct code observations, not a claim that every paper configuration matches the scripts. [Architecture](https://github.com/hkust-zhiyao/GenEDA/blob/0a19fde3f1c1e56f49a367bf5f1914de84e1c951/model/embed_align/model/model/llava_arch.py), [projector](https://github.com/hkust-zhiyao/GenEDA/blob/0a19fde3f1c1e56f49a367bf5f1914de84e1c951/model/embed_align/model/model/multimodal_projector/builder.py), [training script](https://github.com/hkust-zhiyao/GenEDA/blob/0a19fde3f1c1e56f49a367bf5f1914de84e1c951/model/embed_align/scripts/circuit/finetune_lora_summary.sh)

A generic LLM prompted with plain netlist text does not preserve that learned bridge. Hand-written or reference-derived arithmetic names are also not a replacement for the learned gate predictor. Cached author-released features permit a narrower experiment on the learned bridge; cached annotations permit inspecting the decoder input format, but cannot independently establish the predictor that produced them.

## Evaluators and their practical meaning

Tasks 1/2 include BLEU/ROUGE aggregation and API-based semantic scoring. `analyze_embed_similarity.py` calls Azure OpenAI `text-embedding-ada-002`; GPT scoring scripts require a compatible service deployment. These measure language overlap or judged semantic agreement, not circuit equivalence. `analyze_result.py` excludes records below a ROUGE-1 threshold of 0.35; an independent reimplementation must explicitly account for that selection before comparing aggregates. No evaluator was run. [Task 1 evaluator sources](https://github.com/hkust-zhiyao/GenEDA/tree/0a19fde3f1c1e56f49a367bf5f1914de84e1c951/benchmark/task1/eval)

Task 3 has an actual functional checker: testbench source plus makefiles invoking VCS and `auto_run.py` aggregating syntax/function outcomes and pass@k. The inspected testbench uses 100 randomized cases. Passing that testbench is finite simulation evidence, not exhaustive formal equivalence. The driver assumes author-local output paths, looks for `simv`, and recognizes pass text; clean compilation/output isolation would need review before a later run. [Task 3 driver](https://github.com/hkust-zhiyao/GenEDA/blob/0a19fde3f1c1e56f49a367bf5f1914de84e1c951/benchmark/task3/eval/auto_run.py), [sample testbench](https://github.com/hkust-zhiyao/GenEDA/blob/0a19fde3f1c1e56f49a367bf5f1914de84e1c951/benchmark/task3/eval/add_mul_2_bit/add_mul_2_bit_tb.v)

`run_deepseek.py` contains both annotated and plain input assignments; its later active assignment selects plain `netlist_ori` and baseline output naming. A future annotated run must deliberately select the intended input. Reading this file did not call its endpoint or use any embedded credential. [Inference source](https://github.com/hkust-zhiyao/GenEDA/blob/0a19fde3f1c1e56f49a367bf5f1914de84e1c951/model/predict_align/model/inference/run_deepseek.py)

## Resource needs and fidelity of lower-cost substitutions

The following are planning estimates from asset sizes/configs, not measured runtimes or authorization to execute.

| Route or substitution | Concrete resources / fill | Fidelity retained and lost |
|---|---|---|
| Fixed-feature minimum, preferred for learning | Released graph/conversation files, DeepSeek-Coder-1.3B tokenizer/weights, 768-input learned MLP, two-stage connector/LoRA training, PyTorch/Transformers/PEFT/DeepSpeed and corrected package paths. Plan one CUDA GPU around 16–24GB, CPU RAM around 16–32GB and several GB model/dependency storage; hours-scale pilot budget, uncertain until tested. | Retains learned circuit-feature → language mapping. New split on benchmark assets is an educational dataset, not the original holdout. Parent-design grouping must be established or uncertainty disclosed; unseen-circuit generalization and original scores cannot be claimed. |
| Full raw-netlist path | Circuit expression encoder adapters, graph encoder checkpoint/configs, synthesis/graph preparation inputs, original train/validation/test mapping, then connector/LoRA and gate predictor. If unavailable, repeated preprocessing and encoder pretraining plus training data construction. | Preserves full method only if the learned circuit representation is retained. Existing code makes implementation possible; it does not establish that reconstructing all missing assets is cheap. Exact wall time/storage unverified. |
| Cached annotations + local frozen decoder | Twelve annotated netlists, suitable local long-context model, testbenches and a simulator | Useful decoder-side method lesson; preserves prediction conditioning only if annotations are accepted as cached encoder outputs. It cannot validate the learned predictor or its raw-netlist path. A new decoder loses original GPT-4o/DeepSeek-V3 comparability. |
| Hand-written arithmetic labels / plain text LLM | Cheap annotation or prompt work | Loses the learned alignment mechanism. Label-derived oracle hints must be named as such; cannot qualify as the minimum faithful reproduction. |
| Icarus/Verilator instead of VCS | Port/check simulator commands and supported syntax; retain testbench contract | Can retain finite functional simulation intent; tool semantics and acceptance rates may differ. No simulator was installed or run. |
| Local text embeddings/judge instead of API scoring | Local evaluator weights, declared scoring protocol | Retains an approximate language-quality check; original semantic score scale and ranking comparability are lost. It cannot replace Task 3 simulation. |
| Yosys instead of original synthesis flow | Open synthesis tools and compatible cell library/mapping | Retains a synthesized circuit workflow but changes netlist distribution and possibly encoder compatibility. It is unnecessary for the fixed-feature minimum. |

The copied alignment source imports `llava` while living under `model/embed_align/model`; package layout, dependency versions, CLIP scaffolding and checkpoint loading require static repair/reconciliation before running. No such implementation changes were made in this audit. The upstream NetTAG README provides additional reconstruction guidance, but a mention of loading a public checkpoint without an identified compatible URL is not verified weight availability.

## One testable gap/control, proposed only

**Does the decoder learn to use the released circuit features rather than only prompt/signal-name cues?** After identifying parent-design groups and creating a new disjoint educational split, train the small connector/LoRA with the released graph vectors. Evaluate matched vectors versus vectors shuffled across held-out designs, keeping decoder, prompts and decoding fixed. A reliable advantage for matched vectors would support use of circuit information; no advantage would limit the interpretation. This control has not been run and makes no accusation about the authors' experiments. Original training split/provenance should be requested as a concrete asset, not assumed from the benchmark filename.

## Access, audit record and remaining blockers

Public source was fetched with a filtered shallow Git clone and selected source reads. An initial `ls-tree -l` unexpectedly lazily fetched benchmark blobs while obtaining object sizes; it was stopped, and inventory continued without blob-size lookup. The compressed local Git store was approximately 11MiB at the check; the four benchmark JSONs total approximately 122MB uncompressed. Only their schema/count metadata was inspected. No model weights or external full dataset corpus was downloaded. This records the incidental source fetch rather than describing it as metadata-only network transfer.

No gate was bypassed and no license conditions were accepted. NV-Embed-v1 remains a metadata-only gated dependency. The GitHub tree web view failed in the browsing tool; public Git access supplied the source inventory without an access-gate workaround. No API inference/evaluation calls, settings changes or external writes occurred.

Remaining blockers for the full route: verified trained encoder and expression adapters; compatible missing encoder configs; trained connector/decoder adapters; original instruction corpus and design-group splits; learned gate predictor and annotation provenance; reproducible simulator/API evaluator environment. These are **unverified outside the inspected release**, with no denied or pending operation. The audit is complete; execution stops here.

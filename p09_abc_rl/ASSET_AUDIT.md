# P09 — ABC-RL asset audit

**Retrieval-Guided Reinforcement Learning for Boolean Circuit Minimization, ICLR 2024.** Audit date: 2026-10-28. Static inspection only. Goal: learn the mechanism and identify testable gaps, not reproduce bits or headline numbers.

## Decision

| Route | Five-class decision | Confidence | Reason |
|---|---|---|---|
| Minimum faithful mechanism, using published checkpoint as an experimental starting point | **L2: code; cheap completion/repair** | Medium | Author-linked code, checkpoint metadata, AIGs and library exist. Retrieval wiring, paths and several static defects need repair. Checkpoint compatibility/provenance remains unverified. |
| Full-paper training and evaluation | **L3: code; high-cost completion** | High on cost, medium on exact remaining assets | Released refactor differs from the described architecture/split and requires costly synthesis-driven retraining for the paper route. L4/L5 do not apply: author-linked code is confirmed. If the checkpoint cannot support repaired inference, the minimum route becomes L3 because learning usable guidance again dominates cost.

## Mechanism reconstructed

**Paper-level contract** ([arXiv v1 §§2–3, appendices](https://arxiv.org/html/2401.12205v1)): state combines the original AIG and partial recipe. A three-layer GCN uses node type and negated-fanin count; mean/max pooling yields graph features, combined with a single-attention recipe encoder. MCTS-derived policy targets supervise pretrained guidance. Retrieval takes minimum cosine distance to training-graph embeddings, then fixes a sigmoid-derived novelty alpha for the input circuit. Search weights exploration by `policy^(1-alpha)`: alpha approaching one suppresses guidance. Evaluation uses length-ten recipes, mapped 7nm area-delay product relative to resyn2, 23/13/20 train/validation/test circuits and 100 synthesis runs per test circuit. Reported training is 50 epochs, K=512 per level, roughly nine days on an RTX A4000; ABC synthesis dominates. This is contextual evidence from the preprint, not confirmation that the released checkpoint follows that contract.

**Released-code contract**:

- [`LogicSynthesisEnv.py`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/LogicSynthesisEnv.py), lines 10–29 and 73–95, fixes actions to refactor, refactor -z, rewrite, rewrite -z, resub, resub -z, balance. Resub uses k=8, n=1. Episode depth is ten; state filenames carry recipe prefixes. Do not substitute a different command order or library silently.
- The same file, lines 178–213, evaluates with `read_lib; map; topo; stime`; baseline is its explicit resyn2 sequence. Training reward is `max(-1,1-ADP/baselineADP)`. Evaluation CSV reports factor `baselineADP/ADP`, rather than percentage reduction. Convert factor r to percentage as `100*(1-1/r)`; do not average these as interchangeable metrics.
- [`evaluate_synergy.py`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/evaluate_synergy.py), lines 132–142, accepts distance through `--cos`, computes exponent `beta=1-sigmoid(scaling*(distance-threshold))`, and passes beta to MCTS under the variable name `alphaValue`. This naming reversal alone is not a defect: [`mcts.py`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/mcts.py), lines 459–469, raises policy probabilities to that exponent.
- [`evaluate_on_test_circuit.sh`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/evaluate_on_test_circuit.sh) hardcodes distances per design, threshold .007, scaling 100, budget 100 and the exposed checkpoint. This is a manually supplied-distance evaluation entry point, not automatic retrieval for an arbitrary unseen circuit.
- No explicit CEC/equivalence check appears in the inspected environment/evaluation/MCTS paths. ABC transformations are intended to preserve functionality; a faithful port should verify original versus final AIG and reject failures. This is a missing verification contract in inspected paths, not evidence that a circuit is inequivalent.

## Actual static defects and implementation drift

1. **Retrieval scorer does not load its requested policy.** [`cosine_scorer.py`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/cosine_scorer.py), lines 220–225, checks a supplied model path, comments out loading it, then calls `Trainer(preTrainedGraphModel=None)`. [`trainer.py`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/trainer.py), lines 19–56, confirms this initializes a fresh graph policy. Therefore this scorer does not compute distances in the specified pretrained graph space. It also references a different circuit pool, containing test circuits, so it cannot be used unchanged for the paper's train-only retrieval bank. High confidence; no runtime claim.
2. **Graph learning gradient is blocked by rounding.** [`LogicSynthesisPolicy.py`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/LogicSynthesisPolicy.py), lines 156–158, unconditionally rounds the AIG embedding inside forward. Under ordinary PyTorch autograd, round has zero derivative, so the policy/value loss cannot train upstream node/GCN parameters through that path. Static consequence; no gradient test performed. This does not prove how the published checkpoint was trained.
3. **Rollout horizon adds one command.** `LogicSynthesisEnv.py`, lines 201–207, inserts the starting action, then appends `10-depth` random actions. A rollout from depth zero evaluates eleven commands; from depth nine it appends two instead of one. The stored terminal tree path still has depth ten, so rollout scores and terminal objectives differ. High-confidence counting defect; not executed.
4. **Full-paper implementation drift is visible.** Policy defaults use two GCN layers; normalization calls are commented out and graph nonlinearity is ReLU. A module-global full `BertModel.from_pretrained('bert-base-cased')` is used, outside the policy module's registered state. Training split 5001 in [`main.py`](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/ABC-RL_ICLR/src/main.py), line 57, lists 22 training circuits and omits c6288 relative to the paper table. Its script requests 101 runs, and MCTS training uses a per-level budget schedule. These are static differences; correctness and which configuration generated the checkpoint are unverified.
5. **Budget/reporting caveat.** `mcts.py`, lines 646–672, evaluates one root rollout before entering the 100-iteration CSV loop; environment construction separately measures resyn2. Consequently 100 CSV rows are not a complete count of ABC evaluations. Count baseline, initialization, rollouts and terminal evaluations explicitly in a comparison.

Potential method weaknesses, not demonstrated defects: cosine closeness of locally pooled structural embeddings need not predict policy usefulness; calibration on a small validation pool can be brittle; a single fixed per-circuit alpha may miss changes in usefulness across recipe depth. None proves the reported effect false.

## Cost, honest port and useful controlled test

**Inference route:** retain the provided checkpoint only after compatibility validation; restore automatic train-bank cosine retrieval in the same encoder, record hashes of bank/model/circuit/library, parameterize paths, reconcile beta/alpha and temperature convention, repair the horizon and count every synthesis evaluation. Keep the original graph plus recipe state, seven actions, mapped ADP objective and fixed calibrated novelty gate. Add explicit equivalence rejection and robust ABC exit/log handling. A reduced circuit subset can test this mechanism honestly if labeled a pilot. Handcrafted distances, random embeddings or a policy-free gate would not validate learned retrieval guidance.

**Full-paper route:** recover or regenerate a provenance-backed policy with the specified train/validation/test split and intended learned encoder; reconcile architecture and normalization first. Rebuild train-only embeddings and tune the gate on validation only. Run search-only, fixed-guidance and adaptive-guidance comparisons under identical objective/toolchain and counted budget, then reproduce evaluation and architecture ablations. Additional unavailable provenance may be cheap documentation, but regenerating the learned artifacts is high cost. A later DAGNN model does not resolve this route.

The [README](https://github.com/NYU-MLDA/ABC-RL/blob/db6186cb4018963b5bc15926772c3edc0c2873f1/README.md) estimates 10–12 days for ICLR training on A4000, **350–550 GB generated per training**, and about 1 TB for parallel runs. Those are author estimates, not measured here. DAGNN is estimated another 5–6 times slower and is outside the minimum route. Inference still performs ABC synthesis rollouts; retrieval is only a small embedding-bank lookup. No defensible per-circuit runtime or total financial cost was measured. Distinguish amortized pretrained-guidance cost from test-time savings.

**One useful controlled test, proposed only:** after repairing the contract, compare adaptive beta, fixed beta=1 (full guidance), and beta=0 (search exploration prior) on the same held-out circuits, checkpoint, random seeds and exactly counted synthesis-call budget. Fit gate parameters only on validation circuits. Record mapped ADP curves, wall time including retrieval/model work, CEC outcome, actual nearest distance and chosen gate value. Test whether distance predicts the observed advantage of guidance and whether adaptation improves over a tuned fixed gate. These are separately executed searches; do not infer rewards or counterfactual outcomes for actions that were not executed. Also inspect that beta=0 does not leave a policy-dependent rollout rule before calling it pure search.

## Environment and audit boundaries

Selected cloud environment transitioned from starting to **ready**; working directory `/workspace`, Linux x86_64. `python3`, `curl`, and `pdftotext` were found. `abc`, `yosys`, and `nvidia-smi` were not found on PATH; this does not prove no GPU or tool exists elsewhere. Workspace overlay showed 32 GB total and about 30 GB available, below documented full training storage. No GPU probe, package import, install, upstream execution, experiment, inference, EDA run, model deserialization, API call, settings change or push was performed. Only small public page/source downloads and local evidence/report writing occurred; the 45.7 MB library and checkpoint payload were not downloaded.

Cloud direct GETs of the official PDF and arXiv HTML returned HTTP 403 and were not retried. The web retrieval service exposed arXiv text; browser gates/restricted tree results were not bypassed with credentials. Public GitHub page/source GETs from the selected cloud succeeded. Final-paper differences and checkpoint behavior remain unverified. Saved evidence consists of GitHub HTML metadata and selected source snapshots; no claim of a complete repository audit.

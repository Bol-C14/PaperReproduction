# Public Round 2 export — P07 VeriThoughts

This export publishes only `reproduction/verithoughts-neurips2025` in the existing public Bol-C14/PaperReproduction repository. It contains the CPU evaluator-contract pilot, reviewed claim boundaries, preregistered benchmark follow-on/access denial, source/configuration/commands, actual metrics and complete small logs. No new research execution accompanies publication.

One unrelated internal execution-environment identifier in historical `P07_VeriThoughts/assets.json` was replaced with an explicit redaction marker. All seven commits were recreated with that sole historical content change; original authors, timestamps and messages were retained. `PUBLIC_EXPORT_COMMIT_MAP.json` maps original local protocol/evidence commit references to public commits. The original local branch and a preservation ref remain intact, and the previously created private recovery archive is preserved outside this repository. No archive or credential state is published.

All 264 other originally tracked files are byte-identical to the original head. Raw experiment evidence, sources, frozen protocol, inputs, metrics and logs were not altered. The offline scan covers every reachable blob/commit in the proposed public history and all included working files. Patterns cover common token/key forms, private-key markers, literal credentials/auth headers, credential URLs, opaque internal environment IDs and private/internal-service addresses. Source references to API-key arguments are placeholders/variable names, not credentials. Pattern scans cannot guarantee detection of every unknown secret format. No real credential or private-key material was found; the unrelated internal identifier was removed before pushing.

Scientific claims remain bounded: empty discovery is a verified input-validation defect on a synthetic edge case; delayed divergence demonstrates the disclosed finite-horizon limitation; helper omission violates the paper's explicit per-module contract. The benchmark payload remained inaccessible, so its relevance is unknown and no score-inflation or dataset-error-rate claim is made. The only repeated formal command was the separately preregistered logging-only witness capture. Dependency substitutions and setup failures remain recorded.

`PUBLIC_EXPORT_OMISSIONS.json` lists omitted local reconstructible files with sizes/hashes/provenance. Docker environments and caches, source-download cache, simulator executables, recovery bundles/archives and unrelated fetched paper history are not published. No training checkpoints were produced. External pretrained model assets were not downloaded or modified; available metadata/URLs and unverified weight integrity are documented in the asset audit and assets.json. Reconstructing the runtime requires external Debian/GitHub access; obtaining the blocked benchmark remains unresolved. Publication does not change repository visibility or create a PR.

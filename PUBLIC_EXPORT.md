# Public export provenance

This branch is an authorized public reproduction export of the original local research history. Nonresearch runtime process inventory was removed from the commit where it first appeared; Yosys version and CPU count remain. No experimental RTL, graph, measurement, raw synthesis/SAT evidence or conclusions were changed.

PUBLIC_EXPORT_COMMIT_MAP.json maps original local commits to exported commits. Original local branch and the Library v3 bundle remain intact and are not uploaded as bundles here. The map contains hashes only; sanitized-out contents cannot be recovered from uploaded ancestry.

All reachable public history and the proposed tree are screened for credential patterns, sensitive paths, internal endpoints and unrelated infrastructure logs. Cache/tool/model binaries and full per-call netlists remain excluded; selected small raw representative netlists are scientific evidence. Pattern scans are not a mathematical proof of secret absence.

The latest online-versus-open-loop pilot is documentation only: no model API call, no supplied credential persisted, no new EDA. Public repository publication is separately authorized; it does not authorize a model provider request or a free/paid model allocation. Provider/model/free quota binding remains unresolved. After publication work pauses pending confirmation of the new environment.
